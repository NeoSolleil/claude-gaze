# claude-gaze

Claude Code が「いま何を見ているか」をライブなノード／エッジ図で描くローカルツール。
Hooks で届くツール呼び出しを受け取り、主体（メイン／サブエージェント）ごとに色を分けて、
ファイル・URL・検索・MCP・コマンドへのアクセスをブラウザに描きます。

状態: P1（サブエージェント・検索結果の展開・MCP／Skill・Bash 推定・失敗したツール呼び出し・主体別表示・枠の折りたたみ・3D 表示）。構想は [docs/concept.md](docs/concept.md)、UI モックは `mock/`。

## 動かす

要件: Node.js 23.6 以上（TypeScript を直接実行するため）、`curl`。

```sh
npm install
npm start            # http://127.0.0.1:4820/
```

Hooks の登録: このリポジトリの `.claude/settings.json` に入っているので、**このディレクトリで起動した Claude Code** のイベントだけが届きます。
他のプロジェクトでも使うには `hooks/hooks.snippet.json` の内容を `~/.claude/settings.json` に写してください。

サーバが止まっていてもフックは 1 秒で諦めて終了するので、Claude Code 側は遅くなりません。

## 画面

- 左: セッション一覧（最新が上。クリックで切替。URL の `#<セッションID先頭>` でも指定可）と主体一覧（色・live/done・回数）
- 中央: 表示方式を下部で切替
  - **2D 地図**: 左列が Web・コマンド類、中央が主体、右列がディレクトリごとのファイル枠。対象は 1 ノードで、塗りが主体の色（複数ならパイ）。線は主体の色、破線は Bash からの推定、点線の灰色は失敗した呼び出し。枠をクリックすると畳める
  - **2D 主体別**: 主体ごとの帯に分けて表示。同じ対象は帯ごとに出し、`◈n` で共有数を示す
  - **3D**: 力学配置の立体表示（three.js）。粒子が主体から対象へ流れる。左ドラッグ回転・右ドラッグ移動・ホイール、自動回転あり。見せる用途
- 右: クリックしたノード／線／イベントの詳細と、イベント列（主体タブで絞り込み。ノードをクリックすると関連する行に印が付く）
- 下: 一時停止（描画だけ止める。再開時に溜めた分を順に描く）、種類フィルタ、Bash経由（推定）、表示方式、自動で全体表示
- URL パラメータ: `?static=1`（SSE を使わず 1 回の取得で描く。スクリーンショット用）、`?view=map|lanes|3d`（初期表示）

デモ: `sh scripts/demo-session.sh` で架空セッション（主体 3 体、失敗・検索・MCP・Skill・Bash 推定を含む）を投入できる。
